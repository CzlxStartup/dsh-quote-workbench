# 报价工作台 · DeepSeek Harness 插件

左侧 Tab 栏中的「报价工作台」打开原生 React 面板，包含工厂报价、报价核算、货代报价、核算记录；工厂报价的文本解析由大模型完成，解析模型在「设置 → 报价工作台」里选择。界面使用 Harness 主题变量；无需 iframe、独立服务器或额外 React。

## 功能与迁移

- 保留原版人民币采购、美元双汇率采购、自有工厂倒推公式，人民币采购支持国际运费上下限、FCA/CFR 成本、盈亏平衡价与利润区间。
- 粘贴报价（自由文本或 Excel 制表符表格）由 `llm` 服务中的大模型解析为结构化记录，支持多条报价逐条确认；字段经过白名单与类型收敛，模型输出不会被直接信任。
- 支持工厂报价带入成本、同路线同口径有效货代报价比较、核算记录复制重算。
- 信保国家分类和费率沿用原版数据（2026–2027.6 表）；表中没有的组合需手动填写费率。
- 数据保存在 Harness 的 `quote_workbench` 存储域，不再依赖网页 localStorage。当前 Host 中的会话共用这份数据；解析模型的选择也一并保存，重启后保留。
- 原浏览器数据不会自动迁移。在旧页面导出 JSON，再在插件页面点击「导入备份」。导入前会校验内容并要求确认；导入会替换所有现有记录。无效备份不会部分写入。
- 写入使用 revision 校验。其他窗口或 Agent 更新后，点击「刷新记录」再重试即可，表单不会因此清空。

## 解析模型设置

「设置 → 报价工作台」列出当前 Harness 已接入的提供方及其公布的模型，可直接选择，或保持「跟随 Harness 默认模型」。未选择时使用 Harness 默认模型；两者都没有时解析会提示先去设置。模型不可用、超时或返回非 JSON 时会显示明确错误，不会回退成规则解析。

模型列表每次打开设置页时刷新，也可手动刷新。保存即刻生效，下一次解析使用新模型。Agent 也可通过 `quote_workbench` 工具的 `settings` / `models` / `saveSettings` 动作读取和修改同一份设置。

## 源码与构建

原版 dist 保持不变。`domain.js` 是无 DOM 的业务模型；`service.js` 统一执行操作并调用大模型；`index.js` 注册 Host 持久化、受认证保护的 `/api/quote-workbench` 路由和 `quote_workbench` 工具；`ui.js` 与 `style.css` 定义工作台页面与设置页。

在插件目录执行：

```sh
npm ci --ignore-scripts
npm run build
npm test
```

构建会生成 `client.js`，由 Harness 的模块加载器加载。依赖只包含 Host 使用的 zod，没有安装脚本。

本地目录安装使用链接，先安装本目录依赖，再通过 Harness 的 plugin_manager 安装本目录。不要移动或删除已经链接的插件目录。以后修改代码后须重新构建 Client；是否需要重启以 Harness 插件管理器的结果为准。

## 验证

19 项 Node 测试覆盖原公式、信保表边界、解析与字段收敛、模型失败、设置校验、校验器、运费筛选、并发 revision、导入原子性、保存重算与持久化失败。

已在当前 Harness 验证：工具端新增/读取/删除；`models` 列出提供方与模型；`parse` 用 `deepseek-account/deepseek-flash` 解析两条真实报价并正确识别币种、单价、单位、Incoterm、港口和费用承担方；`saveSettings` 保存并恢复为跟随默认；左侧入口与「设置 → 报价工作台」均已注册。自检写入已清理。

当前会话没有浏览器控制能力，未完成实际点击、布局、浅色/深色视觉验收。中英文元数据及原创 SVG 图标已提供；业务字段目前以中文为主。
