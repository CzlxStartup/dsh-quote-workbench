# 报价工作台 · DeepSeek Harness 插件

左侧 Tab 栏中的「报价工作台」打开原生 React 面板，包含产品目录、工厂报价、报价核算、货代报价、核算记录；工厂报价的文本解析由大模型完成，解析模型在「设置 → 报价工作台」里选择。界面使用 Harness 主题变量；无需 iframe、独立服务器或额外 React。

## 功能与迁移

- 保留原版人民币采购、美元双汇率采购，以及自有工厂倒推；人民币/美元采购支持国际运费上下限、FCA/CFR 成本、盈亏平衡价与利润区间。自有工厂倒推同样使用最低/最高国际运费，只填写收汇汇率和增值税率、退税率，不再显示工厂选取与采购单价，并输出人民币含税倒推价和美元不含税倒推价区间。
- 粘贴报价（自由文本或 Excel 制表符表格）由 `llm` 服务中的大模型解析为结构化记录，支持多条报价逐条确认；字段经过白名单与类型收敛，模型输出不会被直接信任。
- 产品目录支持手工维护名称与 CAS，也从工厂报价和历史核算汇集产品；按 CAS 去重、搜索及带入两类表单。输入 CAS 可自动补产品名称；增值税率与退税率也按 CAS 绑定，优先取该产品最近一次人民币/自有工厂核算的税率，没有核算时取工厂报价的税率，都没有时保存后即记住。
- 工厂报价支持编辑、取消编辑、报价日期、保存/修改时间和完整明细展开；核算页来源按币种及 CAS 筛选。工厂列表带入可切换采购模式，核算页带入保持当前模式；核算页选取报价后立即按吨/公斤换算并填入采购单价、退税率、产品和 CAS，交货地点随报价带入，报价含明确数量时同步填入数量。
- 工厂报价表单包含增值税率与退税率（增值税率在退税率之前），输入 CAS 时会按产品绑定自动代入；未保存的报价草稿在离开工作台后保留 10 分钟，超过 10 分钟没有操作则自动清空。
- 人民币和美元采购都提供最低/最高国际运费，并按两者计算 C&F（CFR）成本、盈亏平衡价、利润和利润率的区间。C&F 成本不再要求先填写售价和信保费率；最高运费留空时按最低运费展示单一成本。美元采购不显示增值税率；自有工厂倒推不显示采购单价和买汇汇率。
- 核算中的 Incoterm 是对客条款（customerTerm），不会被工厂条款覆盖；旧版 term 是采购条款，不自动当作对客条款。条款仅记录，不自动改变费用公式。
- 保留 AI 提取，另设无需模型的“规则提取”入口，支持 Excel CAS、报价日期和有效期字段。
- 货代报价页把起运地、目的地拆成两个字段并分别展示；海运整柜只需选择柜型（20GP/40GP/40HQ/45HQ），海运拼箱和空运填写询价数量与单位（默认公斤，可切换吨/CBM/票）；拼箱可选择是否抛货，选择「是」时须填写体积（CBM），抛货报价按数量和体积参与比较。旧记录仍按原来的「路线 + 数量 / 柜型 / 费用范围」展示和比较，兼容导入。
- 支持同起运地、同目的地、同运输方式、同柜型或同询价数量的有效货代报价比较、核算记录复制重算；旧历史缺少最高运费结果时按保存参数补算展示。工厂来源按 dist 逻辑不自动排除过期报价，货代比较会校验有效期。
- 核算记录页可按 CAS 和客户名称关键词筛选：均为「包含」匹配，CAS 忽略分隔符和全角字符（如 6768 可匹配 67-68-5），客户名称忽略大小写；两项同时填写时需同时满足。筛选显示「命中 / 全部」条数并可一键清除，记录行同时显示客户名称。
- 信保国家分类和费率沿用原版数据（2026–2027.6 表）；表中没有的组合需手动填写费率。
- 数据保存在 Harness 的 `quote_workbench` 存储域，不再依赖网页 localStorage。当前 Host 中的会话共用这份数据；解析模型的选择也一并保存，重启后保留。
- 报价核算为人民币采购、美元采购、自有工厂倒推分别保留草稿和已选工厂来源；切换采购模式、切换工作台标签或离开工作台再回来都会恢复各自的数量、价格、费用和汇率，并回到上次所在的工作台标签。草稿保存在当前浏览器会话（sessionStorage），刷新页面不丢失。
- 资金占用月数默认与账期（月）一致，随账期自动填入；也可以手动修改，手动修改后保持该值、不再随账期变化。
- 报价核算（人民币/美元采购）按「01 选取工厂报价（产品、CAS、增值税率/退税率）→ 02 工厂与运输成本（数量、采购单价、汇率、运费、国内费用）→ 03 对客户报价（客户、国家、单价、运输方式与条款）→ 04 其他费率、资金占用情况」分组；自有工厂倒推保留产品与成本两段。
- 原浏览器数据不会自动迁移。在旧页面导出 JSON，再在插件页面点击「导入备份」。导入前会校验内容并要求确认；导入会替换所有现有记录。无效备份不会部分写入。备份包含手工产品目录；旧备份缺少 products 时按空目录导入，工厂/历史中的 CAS 仍可派生目录。旧报价的自由文本有效期保留，编辑时可改为日期。
- 写入使用 revision 校验。其他窗口或 Agent 更新后，点击「刷新记录」再重试即可，表单不会因此清空。
- 工作台右上角提供 A− / A+ 界面缩放（75%–150%），也支持 Ctrl + `-` / Ctrl + `=` 调整、Ctrl + `0` 恢复默认；比例保存在本机浏览器，重开页面仍保留。

## 解析模型设置

「设置 → 报价工作台」列出当前 Harness 已接入的提供方及其公布的模型，可直接选择，或保持「跟随 Harness 默认模型」。未选择时使用 Harness 默认模型；两者都没有时解析会提示先去设置。模型不可用、超时或返回非 JSON 时会显示明确错误，不会回退成规则解析。

模型列表每次打开设置页时刷新，也可手动刷新。保存即刻生效，下一次解析使用新模型。Agent 也可通过 `quote_workbench` 工具的 `settings` / `models` / `saveSettings` 动作读取和修改同一份设置。

## 源码与构建

原版 dist 保持不变。`domain.js` 是无 DOM 的业务模型；`service.js` 统一执行操作并调用大模型；`index.js` 注册 Host 持久化、受认证保护的 `/api/quote-workbench` 路由和 `quote_workbench` 工具；`ui.js` 与 `style.css` 定义工作台页面与设置页。

在插件目录执行：

```sh
npm ci --ignore-scripts
npm run build
npm test
```

构建会生成 `client.js`，由 Harness 的模块加载器加载。依赖只包含 Host 使用的 zod，没有安装脚本。

本地目录安装使用链接，先安装本目录依赖，再通过 Harness 的 plugin_manager 安装本目录。不要移动或删除已经链接的插件目录。以后修改代码后须重新构建 Client；是否需要重启以 Harness 插件管理器的结果为准。

## 验证

Node 测试覆盖原公式、自有工厂倒推的汇率/上下限运费/退税区间、信保表边界、解析与字段收敛、模型失败、设置校验、运费筛选、并发 revision、导入原子性、保存重算与持久化失败，以及产品目录/CAS、日期提取、工厂更新、产品备份兼容。无额外依赖的 UI 事件测试执行实际组件代码，检查来源筛选、核算记录 CAS/客户关键词筛选、条款保留、编辑/取消、目录带入与旧历史区间；它不替代真实浏览器布局验收。

已在当前 Harness 验证：工具端新增/读取/删除；`models` 列出提供方与模型；`parse` 用 `deepseek-account/deepseek-flash` 解析两条真实报价并正确识别币种、单价、单位、Incoterm、港口和费用承担方；`saveSettings` 保存并恢复为跟随默认；左侧入口与「设置 → 报价工作台」均已注册。自检写入已清理。

当前会话没有浏览器控制能力，未完成实际点击、布局、浅色/深色视觉验收。中英文元数据及原创 SVG 图标已提供；业务字段目前以中文为主。
